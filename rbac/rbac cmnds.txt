 Get token:
kubectl -n dev create token dev-user
Save this token.

✅ Use token via kubectl:
Create a new kubeconfig using the token:

kubectl config set-credentials dev-user --token=
kubectl config set-context dev-context --cluster=minikube --user=dev-user --namespace=dev
kubectl config use-context dev-context
Then try:

kubectl get pods         ✅ should work
kubectl delete pod pod-1 ❌ should be denied
